**队伍构筑与策略卡牌**　/　可玩原型 v0.32 · 持续迭代

## 游戏介绍

一款以魔王亲征、招募手下与角色招式配合为方向的中文策略卡牌游戏原型。玩家在远征中收集伙伴与招式，调整队伍与携带选择，通过回合制战斗推进旅程。

## 想带来的体验

- 角色与各自招式共同参与队伍构筑。
- 在远征中招募、收集与整备，尝试不同成员的配合。
- 战斗强调敌方意图、时机选择与队伍之间的协作。
- 二维手绘角色与路线地图呈现魔王重新出发的旅程。
